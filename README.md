# trueform

Restores punctuation and capitalization in raw, lowercase, unpunctuated
English, such as speech-to-text output, without ever adding, dropping or
changing a word.

```
in:   hey can you send me the report by friday i think john has it
goal: Hey, can you send me the report by Friday? I think John has it.
```

(This is the target output. The trained model's actual output on this line
will replace it once the first training run is evaluated.)

## Why the output is word-safe

trueform does not rewrite text. For each input word it predicts two labels:
a casing (lower, Capitalized, UPPER) and a mark to put after the word (none,
`,`, `.`, `?`). The output is then rebuilt from the original words. Each
output word is the input word in one of three casings, optionally followed by
one mark. Lowercase the output and strip those marks and you get the input
back, whatever the model predicted. The tests check this on real lines,
random lines and adversarial inputs (numbers, URLs, apostrophes, hyphens,
non-ASCII text), using untrained models as the adversary.

The LLM backend has the same guarantee through constrained decoding (see
[`trueform/constrained.py`](trueform/constrained.py)). At each step, the model
may only emit tokens that continue the next input word in an allowed casing,
or a mark, or a space, and it may only stop once every word is written.

## Quickstart

```bash
pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu   # or a CUDA build
pip install -e .
```

```bash
trueform "hey can you send me the report by friday i think john has it"
cat transcript.txt | trueform > restored.txt      # one input per line
trueform --model checkpoints/tagger-electra-small "..."   # local checkpoint
```

```python
from trueform import restore, roundtrip_ok

text = "hey can you send me the report by friday i think john has it"
out = restore(text)                      # backend="tagger" (default) or "llm"
assert roundtrip_ok(text, out)
```

The default model id points to the Hugging Face Hub. Until the weights are
published there, train locally (see Reproduce) and pass `--model` or set
`TRUEFORM_TAGGER=checkpoints/tagger-electra-small`.

## Reproduce

```bash
pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu
pip install -e ".[data,dev]"
python scripts/prepare_data.py                                   # downloads, checks hashes, builds data/
python scripts/train_tagger.py --config configs/tagger-electra-small.yaml
python scripts/train_tagger.py --config configs/tagger-electra-small-scratch.yaml
python scripts/evaluate.py --config configs/eval/tagger-electra-small.yaml
python scripts/evaluate.py --config configs/eval/tagger-electra-small-scratch.yaml
python scripts/make_table.py                                     # rewrites the table above
pytest -q
```

Each run has one YAML config with a fixed seed. `evaluate.py` writes
`results/<run>/metrics.json` (all metrics, model and data hashes, git commit,
seed, hardware, date), the resolved config, every prediction, and every line
whose words changed (`failures_*.jsonl`).

The LLM code (`scripts/train_llm.py`, `trueform/llm.py`, the constrained
decoder) is written and tested, but no LLM has been trained or evaluated yet,
so there are no LLM rows in the table.

## Limitations

- English only, and trained on Wikipedia prose. It is weaker on informal
  speech, dialogue and fiction (see the out-of-domain column).
- Four marks only: `!` `;` `:` are folded into `.` and `,`, and quotes,
  brackets and dashes are not produced.
- No speaker turns or paragraphing.
- Three casings per word: mixed case such as "iPhone" or "McDonald" can't be
  produced, and hyphenated names come out as "Russo-austrian".
- Long inputs are processed in overlapping 100-word windows.
